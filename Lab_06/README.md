## 1. Мета та завдання роботи

- **Мета:** Опанувати методологію інженерного автоматизованого тестування програмного забезпечення мовою Python із застосуванням фреймворку `pytest`, інструментів макетування `unittest.mock` (`Mock`, `AsyncMock`) та системи аудиту тестового покриття `pytest-cov`.
- **Основні завдання за Варіантом 4 («Система банківських рахунків»):**
  1. Розробити доменну модель банківського рахунку `Account` з валідацією обов'язкових полів, початкового балансу, операцій `deposit` та `withdraw`, контролю достатності коштів та граничних значень.
  2. Реалізувати інтерфейсні протоколи `AccountRepository`, `Notifier` та `AsyncBankingClient`.
  3. Розробити In-Memory реалізацію `FakeAccountRepository` для детермінованого тестування стану.
  4. Реалізувати сервіс бізнес-логіки `BankingService` та асинхронний платіжний шлюз `AsyncBankingGateway`.
  5. Реалізувати конфігураційний модуль з підтримкою змінних оточення (`monkeypatch`).
  6. Реалізувати модулі імпорту рахунків з CSV (`import_accounts_csv`) та експорту в JSON (`export_accounts_json`) з використанням `tmp_path`.
  7. Створити вичерпний тестовий набір (Unit та Integration tests), що покриває нормальні випадки, граничні сценарії, валідацію, обробку винятків, макетування та асинхронні операції.
  8. Забезпечити суворе дотримання стандартів PEP 8 (`flake8`: 0 зауважень), типізації (`mypy --strict`: 0 помилок) та показник покриття коду розгалуженнями $\ge 80-90\%$ (досягнуто **95.48%**).

## 3. Інструкція із запуску тестів та аудиту якості

### Запуск усіх тестів з детальним виводом:
```bash
pytest -v
```

### Запуск тестів з аналізом покриття коду розгалуженнями (Branch Coverage):
```bash
pytest -v --cov=bank_system --cov-branch --cov-report=term-missing --cov-report=html
```

### Статичний аналіз коду:
```bash
flake8 src tests
mypy src tests
```
